## Описание на проекта

Dental Clinic App е система за управление на пациенти, стоматолози, графици и записани часове в дентална клиника.


## Основни функционалности

* Вход в системата с JWT authentication
* Управление на пациенти
* Управление на стоматолози
* Управление на графици
* Записване и отказване на часове
* Търсене по различни критерии
* Валидация на входните данни
* Pagination и sorting
* Global exception handling

## Използвани технологии

* ASP.NET Core Web API
* Entity Framework Core
* SQLite
* HTML / CSS / JavaScript
* JWT Authentication

## Инсталация и стартиране

1. Отворете проекта във Visual Studio.
2. Стартирайте проекта чрез IIS Express или HTTPS.
3. Отворете:
   http://localhost:8080
